# Numora สำหรับเพื่อน (ต้องใช้รหัสเชิญ)

ลิงก์นี้แยกจากลิงก์เดิม (`thapthimchuea.github.io/numora`) ซึ่งยังใช้ได้ตามปกติ
ข้อมูลผลรางวัลดึงต่อจากลิงก์เดิมแบบสด — ผลงวดใหม่เข้าทั้งสองลิงก์พร้อมกัน

## โครงสร้าง
- `src/worker.js` — ตัวตรวจรหัสเชิญ + หน้าใส่รหัส + หน้าจัดการ `/admin` + ส่งต่อข้อมูล `/data/*`
- `wrangler.toml` — ตั้งค่า Cloudflare (ชื่อ `numora-friends`, KV `CODES`)
- `deploy.mjs` — คัดลอกไฟล์แอปจากโฟลเดอร์แม่ไป `public/` แล้ว deploy

## ค่าลับ (ตั้งครั้งเดียว ไม่อยู่ในไฟล์)
- `ADMIN_PASSWORD` — รหัสเข้าหน้า `/admin` (เจ้าของตั้งเอง)
- `SESSION_SECRET` — สุ่มยาวๆ ใช้เซ็นคุกกี้ (ถ้าเปลี่ยน ทุกเครื่องต้องใส่รหัสใหม่)

## ใช้งานประจำ
- สร้างรหัสให้เพื่อน: เปิด `https://<ลิงก์ใหม่>/admin` → สร้างรหัส → "คัดลอกลิงก์เชิญ" → ส่งให้เพื่อน
- รหัสหนึ่งใช้ได้ 2 เครื่อง/เบราว์เซอร์ (เบราว์เซอร์ + แอปบนหน้าจอโฮม) ปรับได้ตอนสร้าง
- ยกเลิกรหัส: กด "ยกเลิกรหัส" — มีผลภายใน 1 นาที
- อัปเดตแอปหลังวางไฟล์ใหม่ในโฟลเดอร์ numora: `cd friends && node deploy.mjs`

## โควตาฟรีของ Cloudflare
Workers 100,000 ครั้ง/วัน · KV อ่าน 100,000/วัน · เขียน 1,000/วัน — เพียงพอสำหรับเพื่อนหลักร้อยคน
